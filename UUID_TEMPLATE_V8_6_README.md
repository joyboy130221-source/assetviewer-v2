# Form Builder v8.6 - UUID Template

Adds the system template `{{uuid}}`.

## Behavior
- `{{uuid}}` resolves to a UUID v4 generated by the backend.
- The value is generated once per template context/request and reused consistently within that execution.
- It works anywhere that uses the shared Form Builder template renderer, including API URLs, headers, query parameters, bodies, field/default properties, Service Bus settings/messages, workflow values, and Browser RPA actions.
- The token is displayed in **Available Fields** and can be clicked to insert it into the active template editor.

Example:

```text
https://example.com/api/workorders/{{uuid}}
```

```json
{
  "requestId": "{{uuid}}",
  "assetNumber": "{{assetNumber}}"
}
```

No database migration is required.
