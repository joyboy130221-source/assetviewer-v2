# Form Builder v8.4 - Theme Width & Maximo Field Refinement

- SAP and Maximo themed public forms now use the same 760px maximum form width as the BIB Default theme.
- Single-column layout is retained.
- Maximo controls were refined to more closely match the supplied Maximo Manage reference: white flat fields, square corners, neutral bottom border, no field shadow, compact Carbon/Manage-style labels and focus treatment.
- Existing workflow execution observability and submission result UI are retained.
