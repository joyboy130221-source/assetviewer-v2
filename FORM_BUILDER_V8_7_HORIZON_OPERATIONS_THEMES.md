# Form Builder v8.7 — Horizon & Operations Themes

Adds two BIB-owned visual themes without changing the existing Default, Classic ERP, or Carbon themes.

- **Horizon** (`horizon`) — modern cloud ERP styling with spacious layout, soft surfaces, rounded controls and a polished public-form presentation.
- **Operations** (`operations`) — compact operational/EAM styling with stronger grouping, denser controls and a field-service oriented visual language.

Both themes are available when creating a form and from Form Properties, and are automatically honored by Preview and the published User Form page through the existing `form-theme-*` mechanism.

No database migration is required because the form theme is already stored in the form settings JSON.
